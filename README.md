# PVC PRO

Tarayıcı tabanlı PVC kapı/pencere 2D şematik çizim, yaklaşık metraj ve maliyet, müşteri ve teklif yönetimi uygulaması.

## Yayınlama
GitHub deposunda Settings → Pages → Deploy from a branch → main → /(root) seçip kaydedin. Yayınlandıktan sonra GitHub Pages adresinden açabilirsiniz.

## İlk sürüm
- Pencere, balkon kapısı, giriş kapısı, sürme, panjur ve sineklik ürün türleri
- Ölçüye göre şematik 2D ön görünüş ve açılım yönü
- Profil/cam/aksesuar fiyat listesi ve seri bazlı fiyatlar
- Fire, işçilik, montaj, hedef kâr, minimum kâr ve KDV hesabı
- Müşteri kaydı, teklif arşivi, yazdırma/PDF çıktısı
- JSON yedekleme ve geri yükleme

## Önemli
Bu sürüm yaklaşık teklif ve metraj aracıdır; doğrulanmış üretim kesim listesi değildir. Profil marka/seri geometrisi, kaynak payı, çelik takviye, aksesuar reçetesi ve optimizasyon sonraki geliştirme aşamasındadır. Başlangıç fiyatları örnektir; kendi tedarikçi fiyatlarınızla değiştirin. Kayıtlar tarayıcının yerel depolamasında tutulur.
